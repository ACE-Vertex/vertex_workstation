language-aware precision pass while removing two pieces of idle UI noise:

actually scanning or reading, because visible processing state remains useful.

Python from-import, module bindings, Python functions/classes/decorators,
TS/JS imports/functions/interfaces/types/bindings/React candidates,
Rust facts, and line/column Evidence.
